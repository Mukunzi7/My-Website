# Brand Decision: EduBridge

The platform name is kept as **EduBridge**.

The website footer still protects the product under:

```text
Nexus Company Ltd
```

Every page includes:

```text
© 2026 Nexus Company Ltd. All rights reserved.
```

## Logo

EduBridge now has a built-in luxury logo mark in the header and footer. It is embedded as SVG in the site, so no separate image file is required.

## Domain note

Because many websites use similar EduBridge names, you should still check domain and trademark availability before buying a domain or launching publicly.
